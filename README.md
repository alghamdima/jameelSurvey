# Jameel Surveys

منصة استبيانات عربية/إنجليزية باستخدام FastAPI وSQLite.

## تشغيل محلي

1. ثبّت Python 3.11 أو أحدث واعتماديات التشغيل: `python -m pip install -r requirements.lock`.
2. انسخ `.env.example` إلى `.env`، واضبط مفتاحًا عشوائيًا وكلمة مرور إدارة قوية. يرفض التطبيق القيم الافتراضية. إعداد التشخيص هو `SURVEY_DEBUG`.
3. رفع قائمة الموظفين اختياري. يمكن تشغيل التطبيق وإنشاء استبيان دون أي ملف موظفين، أو رفع قائمة مخصصة من صفحة الاستبيان.
4. شغّل:

```sh
python -m alembic upgrade head
python -m app.cli.bootstrap
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

في بيئة Windows الحالية يمكن استخدام `.tools/python/python.exe` بدل `python`.
بيانات الدخول المحلية المنشأة أول مرة محفوظة في `private/initial-admin.txt`؛ هذا الملف وملف البيئة وCSV مستبعدة من Git وصورة Docker.

## القائمة المركزية الاختيارية (للاستيراد الإداري فقط)

- الأرقام نصوص من 1 إلى 50 خانة، وتُحفظ أصفار البداية.
- تُوحّد الأرقام العربية والفارسية، وتُزال المسافات وعلامات الاتجاه.
- يجب تصدير العمود كنص من Excel؛ لا يمكن استرجاع أصفار فقدها المصدر أصلًا.
- تُرفض القيم غير الرقمية والملفات الفارغة قبل تعديل القائمة، وتُزال التكرارات.
- الاستيراد التالي يستبدل القائمة المركزية النشطة داخل معاملة واحدة. هذه القائمة لا تتحكم بأهلية المشاركة؛ التقييد يعتمد فقط على قائمة الاستبيان المخصصة.
- لا تعرض أرقام الموظفين في مجلد static أو داخل المستودع.
- القائمة تثبت أن الرقم مسموح، ولا تثبت هوية صاحبه؛ يمكن إضافة الدخول المؤسسي لاحقًا.
- يفحص الخادم أهلية الرقم عند بدء المشاركة وعند إرسالها، ويمنع المشاركة المكررة بقيد قاعدة البيانات.

لتحديث القائمة أثناء التشغيل:

```sh
python -m app.cli.import_employees --file employee.csv
```

## Docker

```sh
docker compose up --build -d
```

يتطلب ملف البيئة فقط. تُنفذ الترحيلات وتهيئة المسؤول قبل تشغيل العمال، ولا يلزم وجود CSV.
تُحفظ قاعدة البيانات والصور وقوائم الاستبيانات في وحدات التخزين الدائمة؛ لا يحتاج التشغيل إلى تركيب ملف موظفين.
ينشئ Compose شبكة افتراضيًا؛ للربط بشبكة موجودة اضبط `SURVEY_NETWORK_EXTERNAL=true` و`SURVEY_NETWORK_NAME`.
اضبط `BASE_URL` إلى عنوان HTTPS الفعلي خلف الوكيل؛ يتحدد علم Secure للكوكيز من هذا العنوان.
عند الترقية من تخزين الصور داخل مجلد المصدر، تأكد من نقل الصور الحالية إلى وحدة الصور الدائمة.
تحديث الشفرة يستلزم إعادة بناء الصورة.

## الترقية والنسخ الاحتياطي

قبل ترقية تثبيت فعلي خذ نسخة متسقة من SQLite باستخدام واجهة backup الخاصة بـSQLite، واحفظ نسخة من الصور وقائمة الموظفين في مكان خاص.
الترحيل 0004 يرفض المتابعة إذا وجد معرّفات أسئلة مكررة في بيانات قديمة؛ يجب مراجعتها قبل الترقية دون حذف إجابات تلقائيًا.
تُبطل صيغة الرموز الجديدة الجلسات القديمة، ويلزم تسجيل الدخول مجددًا.
تُرقّى تجزئة كلمة المرور القديمة عند تسجيل الدخول، وتُستبدل كلمات المرور الافتراضية القديمة بالقيمة الآمنة من البيئة عند التهيئة.
تغيير كلمة المرور في البيئة وحده لا يغيّر كلمة مرور مخصصة موجودة في قاعدة البيانات.

## الاختبارات

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q tests
node tests/frontend.test.js
```

اختبارات Python تستخدم قاعدة مؤقتة وأرقامًا اصطناعية، وتشمل الترحيلات، استيراد القائمة، الأهلية، التزامن، الجلسات، CSRF، صحة الأسئلة، الصور، والتصدير.
اختبارات JavaScript تتحقق من حفظ المسودات واسترجاعها وتفرّد معرّفات الأسئلة والخيارات.

## حدود تشغيلية

- معدلات الحماية الحالية: 20 محاولة دخول لكل 5 دقائق، و60 طلب تحقق أو إرسال لكل دقيقة، لكل عنوان عميل. راجعها عند وجود عدد كبير من الموظفين خلف عنوان شبكة واحد.
- الرفع محدود بـ10 MB للصورة و25 مليون بكسل؛ لا تُقبل ملفات تالفة.
- الإجابة النصية محدودة بـ10,000 محرف.
- SQLite مناسب لحجم صغير إلى متوسط؛ اختبر الحمل الفعلي قبل التوسع.
- صفحات النتائج والتصدير ما زالت تقرأ مشاركات الاستبيان كاملة؛ تقسيم النتائج والتصدير الخلفي تحسين لاحق عند زيادة البيانات.

## تحديد المشاركين لكل استبيان

في صفحة إنشاء الاستبيان أو تعديله، استخدم قسم **الموظفون المسموح لهم بالمشاركة**:

- **بدون قائمة محددة:** الوضع الافتراضي. يقبل أي رقم وظيفي صحيح حتى إن لم يكن مسجلاً في القائمة المركزية، مع منع تكرار المشاركة.
- **موظفون محددون من ملف CSV:** نزّل القالب الفارغ، وضع رقمًا في كل صف تحت عمود Employee No. ثم ارفع الملف واحفظ الاستبيان.
- القائمة المخصصة مستقلة ولا تحتاج تسجيل أرقامها مسبقًا. الملف غير الصحيح يرفض التغييرات كاملة.
- حد الملف 2 MB. تُحفظ الأصفار وتُوحّد الأرقام العربية وتُزال التكرارات.
- يظهر عدد الأرقام المحفوظة. عند التعديل، ترك الملف فارغًا يحتفظ بالقائمة؛ رفع ملف جديد يستبدلها.
- تغيير الجمهور بعد بدء المشاركة لا يمس الإجابات السابقة. الموظف المستبعد لا يستطيع إرسال إجابة جديدة حتى لو بدأ التعبئة سابقًا.
- نسخ الاستبيان ينسخ قائمة جمهوره، وحذف الاستبيان يحذف تخصيص قائمته فقط.
- لا يُحفظ الملف المرفوع في مجلد عام أو في Git؛ تُخزّن العضوية في قاعدة البيانات.
- شغّل الترحيلات حتى 0006_optional_employee_roster لتفعيل السلوك الاختياري.
